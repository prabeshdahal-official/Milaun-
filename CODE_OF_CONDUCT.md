# Code of conduct

## Our commitment

This project deals with identity data belonging to people who are often not in the
room: patients, beneficiaries, applicants. Contributors are expected to act with
care for those people, and with respect for each other regardless of age, body,
disability, ethnicity, gender identity, level of experience, nationality, personal
appearance, race, religion, caste, or sexual identity.

## Expected behaviour

- Be direct about technical problems and generous about the people behind them.
- Critique code, evidence and claims, not individuals.
- Assume good faith, but ask for evidence when a claim affects users.
- Respect privacy: never post real names, identity numbers, addresses or records
  from a live system in an issue, pull request, test or screenshot.
- Accept that "this needs a labelled dataset first" is a valid review comment.

## Unacceptable behaviour

- Harassment, insults, or discriminatory jokes and language.
- Publishing someone's private information without permission.
- Using the project to build a tool intended to surveil, deanonymise or harass
  individuals or marginalised groups.
- Dismissing reports of harm because the data is "just names".

## Scope

This code applies in all project spaces (issues, pull requests, discussions,
commit messages, code comments) and when representing the project elsewhere.

## Reporting

Report concerns to the maintainer listed in `CITATION.cff`. Reports are handled
confidentially. Maintainers may remove comments, reject contributions, or ban
participants when this code is violated, and will explain the decision when it is
safe to do so.
